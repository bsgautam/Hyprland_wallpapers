# 🚀 Installation / Usage

Clone the repository:

```bash
git clone https://github.com/your-username/Hyprland_wallpapers.git
```

Go inside the folder:

```bash
cd Hyprland_wallpapers
```

Set wallpapers using your favorite wallpaper manager:

- 🖼️ hyprpaper
- 🌊 swww
- 🎨 waypaper
- 🐧 nitrogen
- ⚡ Any wallpaper utility you like
